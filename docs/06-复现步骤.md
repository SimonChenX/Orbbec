# 06 · 从零复现（完整命令序列）

> 假设你拿到一台**全新的树莓派 + Astra Pro Plus**，想复现当前状态。
> 全部命令可直接复制执行。**已做过的一次性步骤会标注**。

---

## 阶段 0 · 连通性

```bash
ping -c 2 192.168.10.76
nc -z -w2 192.168.10.76 22 && echo "port 22 OPEN"

# 口令落盘（若还没有）
printf '%s' '<ROOT_PASSWORD>' > ~/.pi-pass && chmod 600 ~/.pi-pass

sshpass -f ~/.pi-pass ssh -o StrictHostKeyChecking=no root@192.168.10.76 \
  'uname -m; . /etc/os-release && echo $PRETTY_NAME; uname -r'
# 期望: aarch64 / Debian GNU/Linux 13 (trixie) / 6.18.50+rpt-rpi-v8
```

## 阶段 1 · 确认相机在不在

```bash
sshpass -f ~/.pi-pass ssh root@192.168.10.76 '
  lsusb | grep -i orbbec
  echo ---
  v4l2-ctl --list-devices | sed -n "/Astra/,+3p"
  echo ---
  v4l2-ctl -d /dev/video0 --list-formats-ext | head -20
'
```

**期望**（关键！必须看到**两个**设备）：

```
Bus 001 Device 055: ID 2bc5:0501  Orbbec  Astra Pro HD Camera
Bus 001 Device 056: ID 2bc5:0403  Orbbec  Astra Pro
```

看到了 → 继续。只看到一个或都没有 → 查 USB 供电 / 换口（见 `docs/04` 排障树）。

## 阶段 2 · 彩色（**不需要 SDK，直接就能跑**）

```bash
sshpass -f ~/.pi-pass ssh root@192.168.10.76 '
  mkdir -p /opt/orbbec/cap
  cd /opt/orbbec/cap
  # 180° 校正后的抓帧
  ffmpeg -hide_banner -loglevel error -f v4l2 -input_format mjpeg \
    -video_size 1280x720 -i /dev/video0 -frames:v 1 -vf "hflip,vflip" -y color.jpg
  ls -l color.jpg'
```

**期望**：`color.jpg` 约 19~50 KB，`ffprobe` 显示 1280x720。

```bash
# 取回本机看
sshpass -f ~/.pi-pass scp root@192.168.10.76:/opt/orbbec/cap/color.jpg ./
magick identify color.jpg
```

## 阶段 3 · 部署 Orbbec SDK v1（**一次性**）

### 3.1 在开发主机下载（需代理）

```bash
export https_proxy=http://192.168.5.8:7890 http_proxy=http://192.168.5.8:7890
# 到 https://github.com/orbbec/OrbbecSDK/releases 找
#   OrbbecSDK_C_C++_v1.10.37_..._linux_arm64_release.zip
# 本机已有备份: /root/orbbec/sdk_arm64.zip
unzip -q sdk_arm64.zip -d sdk/
ls sdk/OrbbecSDK_v1.10.37/{SDK,Example,Script}
```

### 3.2 打包（只带需要的）

```bash
cd sdk/OrbbecSDK_v1.10.37
tar czf /root/orbbec/sdk_deploy.tgz SDK/lib SDK/config Example/bin Script
ls -lh /root/orbbec/sdk_deploy.tgz        # 约 39MB
```

### 3.3 推送到树莓派并解压

```bash
sshpass -f ~/.pi-pass scp /root/orbbec/sdk_deploy.tgz root@192.168.10.76:/tmp/
sshpass -f ~/.pi-pass ssh root@192.168.10.76 '
  mkdir -p /opt/orbbec
  tar xzf /tmp/sdk_deploy.tgz -C /opt/orbbec
  chmod +x /opt/orbbec/Example/bin/* /opt/orbbec/Script/*.sh 2>/dev/null
  ls /opt/orbbec'
```

### 3.4 装 udev 规则（**一次性**）

```bash
sshpass -f ~/.pi-pass ssh root@192.168.10.76 '
  cd /opt/orbbec/Script && sh install_udev_rules.sh
  ls -l /dev/astra_pro'
```

### 3.5 验证 SDK 能认到设备

```bash
sshpass -f ~/.pi-pass ssh root@192.168.10.76 '
  cd /opt/orbbec/Example/bin
  LD_LIBRARY_PATH=/opt/orbbec/SDK/lib ./HelloOrbbec'
```

**期望**：

```
Device name: Astra Pro
pid: 1027 (0x0403)   vid: 11205 (0x2bc5)
firmware: RD108C-009   serial: 17121620113
ConnectionType: USB2.0
sensor types: IR + Color + Depth
```

## 阶段 4 · 深度 / IR 采集

```bash
# 推送脚本
sshpass -f ~/.pi-pass scp /home/Orbbec/scripts/ob_depth.py \
                            /home/Orbbec/scripts/ob_ir.py \
                            root@192.168.10.76:/root/

# 跑深度（3 帧）
sshpass -f ~/.pi-pass ssh root@192.168.10.76 '
  cd /opt/orbbec/Example/bin
  LD_LIBRARY_PATH=/opt/orbbec/SDK/lib python3 /root/ob_depth.py 3'

# 跑 IR（2 帧）
sshpass -f ~/.pi-pass ssh root@192.168.10.76 '
  cd /opt/orbbec/Example/bin
  LD_LIBRARY_PATH=/opt/orbbec/SDK/lib python3 /root/ob_ir.py 2'
```

**期望输出**：

```
选用深度 profile #2: 640x480 Y11
[OK] 深度流已启动
  帧 0: 640x480 scale=1.0 | 有效 254196/307200 (82.7%) | 深度 66~252mm 均值 197mm
```

## 阶段 5 · 一键抓全套（推荐用这个）

`scripts/capture_all.sh` 会把**彩色（已 180° 校正）+ 深度 + IR** 一次抓齐：

```bash
sshpass -f ~/.pi-pass scp /home/Orbbec/scripts/capture_all.sh root@192.168.10.76:/root/
sshpass -f ~/.pi-pass ssh root@192.168.10.76 'sh /root/capture_all.sh'
```

```
ir_0.png       IR（640x480，灰度）
```
